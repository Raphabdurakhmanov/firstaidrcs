# Портал первой помощи — Красный Полумесяц Узбекистана

Учебный портал для волонтёров и всех желающих: 28 тем по пособию Красного Полумесяца (обновлены по рекомендациям ERC 2025), 84 вопроса, тренажёры, экзамен, личный кабинет, новости и админ-панель. Интерфейс на русском, английском и узбекском.

Стек: **Next.js 15 + Supabase (база, вход через Google, хранилище картинок) + Vercel**, всё на бесплатных тарифах.

---

## Что внутри

| Раздел | Что умеет | Где в коде |
|---|---|---|
| Темы | 28 тем в 5 разделах: признаки, шаги, чего не делать, когда звонить 103, иллюстрации с подписями, пометка «Обновлено» там, где пособие устарело | `lib/content/*`, `app/topics` |
| Поиск | По словам с учётом окончаний («сердце» находит «сердца»), фильтр по разделам | `lib/search.ts`, `components/TopicBrowser.tsx` |
| Тренажёры | Метроном СЛР 110/мин со счётом 30:2 и проверкой вашего темпа, алгоритм «Что делать?», сценарий звонка в 103, тест на инсульт, чек-лист аптечки | `components/tools/*`, `app/tools` |
| Тесты | Мини-тест в каждой теме и экзамен: 15 вопросов из разных тем без повторов, честное перемешивание ответов, разбор ошибок | `lib/quiz.ts`, `components/Quiz.tsx`, `app/exam` |
| Кабинет волонтёра | Вход через Google, прогресс по обязательным темам, история тестов, подтверждение онлайн-обучения (печать или PDF) | `app/cabinet` |
| Новости | Для всех или только для волонтёров | `app/news` |
| Админ-панель | Координаторы добавляют и меняют темы (тексты на 3 языках, шаги, фото, вопросы), новости; администратор назначает роли | `app/admin`, `components/admin/*` |
| База и права | Таблицы, триггеры, политики доступа (RLS), бакет для картинок | `supabase/schema.sql` |

**Как устроены темы.** 28 тем встроены в код и работают даже без базы. Тема, сохранённая в админке, хранится в Supabase и заменяет встроенную с тем же адресом. Кнопка «Вернуть встроенный текст» удаляет изменённую версию. Чтобы скрыть тему, снимите галочку «Опубликована».

**Без Supabase** сайт работает как учебник: темы, тренажёры и тесты доступны, нет только входа, кабинета, новостей и админки.

## Запуск: пошагово (≈30 минут)

### 1. Supabase

1. [supabase.com](https://supabase.com) → **New project** (отдельный от CodePair; регион — Frankfurt).
2. **SQL Editor → New query** → вставьте `supabase/schema.sql` → **Run**.
3. **Project Settings → API**: скопируйте `Project URL` и ключ `anon` / `publishable`.

### 2. Вход через Google

Можно использовать тот же Google OAuth client, что у CodePair:

1. [Google Cloud Console](https://console.cloud.google.com) → **APIs & Services → Credentials** → ваш OAuth client (Web application).
2. В **Authorized redirect URIs** добавьте `https://<НОВЫЙ-ПРОЕКТ>.supabase.co/auth/v1/callback`.
3. Supabase → **Authentication → Sign In / Providers → Google** → включите и вставьте Client ID и Client Secret **от одного и того же клиента**.

### 3. GitHub и Vercel

1. Загрузите папку проекта в новый репозиторий GitHub (без `node_modules` и `.next`).
2. [Vercel](https://vercel.com) → **Add New → Project** → выберите репозиторий. Фреймворк определится сам (Next.js).
3. **Environment Variables**:
   - `NEXT_PUBLIC_SUPABASE_URL` — Project URL;
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` — anon / publishable key;
   - `NEXT_PUBLIC_SITE_URL` — адрес сайта, например `https://firstaid-uz.vercel.app`.
4. **Deploy**.

### 4. Адреса перенаправления

Supabase → **Authentication → URL Configuration**:

- **Site URL**: адрес сайта на Vercel;
- **Redirect URLs**: `https://<ваш-сайт>.vercel.app/**` (и `http://localhost:3000/**` для локальной работы).

Без этого после входа браузер уйдёт на localhost — так было с CodePair.

### 5. Первый администратор

Войдите на сайт через Google, затем в **SQL Editor** выполните:

```sql
update public.profiles set role = 'admin' where email = 'ваша@почта.com';
```

Дальше роли «координатор» и «администратор» можно выдавать в админ-панели → «Волонтёры».

## Локально

```bash
npm install
cp .env.example .env.local   # впишите URL и ключ Supabase
npm run dev                  # http://localhost:3000
npm test                     # тесты экзамена, поиска и контента
npm run build                # сборка, как на Vercel
```

## Как добавить тему без админки

Добавьте объект в `lib/content/topics-*.ts`, а картинки положите в `public/media/<адрес-темы>/` (`1.webp` — обложка, `2.webp`, `3.webp`… — галерея по порядку подписей). Тест `npm test` проверит, что все переводы заполнены, картинки на месте и в каждом вопросе 4 разных варианта.

## Перед публичным запуском

1. **Медицинская проверка.** Протоколы сверены с ERC 2025 и IFRC 2020, но их должен проверить инструктор Красного Полумесяца — особенно пометки «Обновлено», где сайт расходится со старым пособием.
2. **Эмблема.** Эмблема Красного Полумесяца защищена законом: портал нужно согласовать с Обществом Красного Полумесяца Узбекистана.
3. **Узбекский перевод** сделан без носителя языка — его стоит вычитать.
4. **Фото** взяты из учебного пособия. Права на них — у их авторов, это нужно уточнить в той же организации.

Источники: учебное пособие «Первая помощь» Общества Красного Полумесяца Узбекистана; [ERC Guidelines 2025](https://www.cprguidelines.eu); IFRC International First Aid, Resuscitation and Education Guidelines 2020.
